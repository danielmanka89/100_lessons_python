# Step 4: The sep Parameter

- sep stands for "separator"
- It controls what goes BETWEEN items in a print() statement
- Default is a space: print("a","b","c") → a b c
- You can change it to anything: sep="-", sep="|", sep=", ", sep=""
- Examples I tried:
  - print("apple","banana","cherry", sep="|") → apple|banana|cherry
  - print("red","blue","green", sep=", ") → red, blue, green
  - print("red","blue","green", sep="") → redbluegreen

=====================================================================

# Step 5: The end Parameter

- end controls what comes AT THE END of a print() statement
- Default is end="\n" (new line)
- You can change it to anything

## Examples I tried:

| Code | Output |
|------|--------|
| print("Hi", end="") print("There") | HiThere |
| print("Hello", end=" ") print("World") | Hello World |
| print("Loading", end="") print(".", end="") print(".", end="") print(".") | Loading... |

## Difference between sep and end:

- sep = what goes BETWEEN items in ONE print()
- end = what goes AFTER all items in a print()

## More Examples I tried:

| Practice | Code | Output |
|----------|------|--------|
| 4 | print("Step 1", end=" ") print("Step 2", end=" ") print("Step 3") | Step 1 Step 2 Step 3 |
| 5 | print("Counting:", end="") print(1, end="") print(2, end="") print(3) | Counting:123 |
| 6 | print("Buying", end="") print(".", end="") print(".", end="") print(".", end=" ") print("Done!") | Buying... Done! |
| 7 | print("A", end="") print("B", end="") print("C") | ABC |
| 8 | print("Timer:", end=" ") print(3, end=" ") print(2, end=" ") print(1, end=" ") print("GO!") | Timer: 3 2 1 GO! |

## Key Takeaway:
- end controls what comes AFTER all items
- Use end="" for no space and no new line
- Use end=" " for a space, no new line
- Default end="\n" (new line)

# Step 6: Special Characters - New Line (\n)

## What is \n?
- \n creates a new line inside a single print() statement
- It stands for "new line"

## Examples I tried:

| Code | Output |
|------|--------|
| print("First\nSecond\nThird") | First<br>Second<br>Third |
| print("I love\nPython\nProgramming") | I love<br>Python<br>Programming |
| print("Item 1: Apple\nItem 2: Banana\nItem 3: Cherry") | Item 1: Apple<br>Item 2: Banana<br>Item 3: Cherry |

## Key Takeaway:
- \n lets you print multiple lines using ONE print() statement
- Without \n, you would need multiple print() statements

=====================================================================

# Step 7: Special Characters - Tab Space (\t)

## What is \t?
- \t adds a tab space (usually 4-8 spaces)
- Helps align text neatly in columns

## Examples I tried:

| Code | Output |
|------|--------|
| print("Fruit\tQuantity\nApple\t5\nBanana\t3") | Fruit    Quantity<br>Apple    5<br>Banana   3 |
| print("Student\tScore\nJohn\t95\nLisa\t87\nMark\t92") | Student    Score<br>John       95<br>Lisa       87<br>Mark       92 |
| print("City\t\tPopulation\nTokyo\t\t37M\nDelhi\t\t32M\nNew York\t18M") | City          Population<br>Tokyo         37M<br>Delhi         32M<br>New York      18M |

## Key Takeaways:
- \t adds tab space
- \n creates new line
- Use \t\t (two tabs) for extra spacing
- Combine \t and \n for clean tables

# Step 8: Printing Blank Lines

## What is a blank line?
An empty line with nothing printed. Used to make output easier to read.

## Method 1: Using print() with nothing inside

```python
print("Hello")
print()
print("World")
```

### OUTPUT:
```
Hello

World
```

### Explanation:

print("Hello") prints Hello
print() prints a blank line
print("World") prints World

# Method 2: Using \n\n inside a single print()

```python
print("Hello\n\nWorld")
```

### OUTPUT:
```
Hello

World
```

### Explanation:

\n means new line
\n\n means two new lines = one blank line

## Multiple Blank Lines

### Using multiple print():
```python
print("Start")
print()
print()
print("End")
```

### Output:
```
Start


End
```

### Using multiple \n:
```python
print("Start\n\n\nEnd")
```

### Output:
```
Start


End
```

# Step 9: Common Errors and Fixes

## Errors I learned to fix:

| Error | Wrong Code | Fix |
|-------|------------|-----|
| Forgetting quotes | `print(Hello)` | `print("Hello")` |
| Missing closing quote | `print("Hello)` | `print("Hello")` |
| Mixing quotes | `print("Hello')` | `print("Hello")` |
| Missing comma before sep | `print("a","b" sep="-")` | `print("a","b", sep="-")` |
| Quotes inside quotes | `print("He said "Hello"")` | `print('He said "Hello"')` |

## Key Takeaways:
- Always put text inside quotes
- Always close your quotes
- Use same quote type to open and close
- sep and end must come AFTER all items
- Use single quotes outside when you need double quotes inside
