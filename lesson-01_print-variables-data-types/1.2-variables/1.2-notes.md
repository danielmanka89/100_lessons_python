# Lesson 1.2: Variables - Complete Notes

## What is a variable?
A variable is a container that stores a value.

## Creating variables
```python
name = "Daniel"      # String
age = 25             # Integer
price = 2.99         # Float
is_learning = True   # Boolean
```

# Printing variables

print(name)          # Prints Daniel
print(name, age)     # Prints Daniel 25

# Changing variable values

score = 0
score = 5
score = 10           # Value changes each time

# Multiple variables in one line

a, b, c = 1, 2, 3
city, state = "Chicago", "Illinois"

# Variable naming rules (REMEMBER THESE!)

Rule	                                Valid Example       	        Invalid Example
Start with letter or underscore         name, _name	                    1name ❌
No spaces	                            my_city	                        my city ❌
No special symbols	                    score_1	                        score# ❌
No Python keywords	                    my_print	                    print ❌
